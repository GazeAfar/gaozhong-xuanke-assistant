# 高中选科助手 开发与验收计划

版本：0.1　日期：2026年11月25日

## 实施顺序

| 阶段 | 产物 | 进入下一阶段条件 |
| --- | --- | --- |
| M0 文档评审 | 本套文档、决策表、三页布局稿 | 首发范围、输入方式、技术方案和免费边界达成一致 |
| M1 规则与演示 | 可测试引擎、模拟数据、12 组合真值表 | 输入校验、并列、冲突、缺失信息等测试通过 |
| M2 核心小程序 | 首页、填写、报告、全部组合、比较、记录 | 核心流程真机可用，无登录和广告阻挡 |
| M3 数据与查询 | 官方数据导入校验、专业查询详情、来源和版本 | 来源及使用范围核实，抽检及表达式真值检查通过 |
| M4 发布准备 | 隐私说明、主体与类目、性能检查、体验版 | 真实家庭试用无阻断问题，发布与回退可执行 |
| M5 广告实验 | 单一末尾广告位，后续可选权益方案 | 平台资格与规范核实，核心指标不受明显影响 |

不预先承诺几天完成；M0 后结合开发者可用时间估算。每阶段应有独立可运行或可检查的产物，不一次铺开全国库和复杂后台。

## 引擎验收案例

| 编号 | 输入或场景 | 预期 |
| --- | --- | --- |
| T01 | 江苏 3+1+2 配置 | 恰好 12 个无重复合法组合 |
| T02 | 非法三科或不支持省份 | 明确校验失败，不生成伪结果 |
| T03 | 六科优势完全相同且无兴趣 | 全部并列，不声称有唯一最优 |
| T04 | 优势与兴趣均完整 | 按 03 公式计算；示例内部值为 75 |
| T05 | 兴趣仅填写部分 | 全组合统一不用兴趣评分，保留描述 |
| T06 | 优势已知仅三科 | 不排序，显示补充入口和组合浏览 |
| T07 | 优势已知四科 | 只排序三科均已知的组合，其余待补充 |
| T08 | 专业 ALL 物理 化学 | 物化地满足，物生地不满足 |
| T09 | 条件或来源无法解析 | unknown，不当作不满足 |
| T10 | 目标年无数据，仅有参考年 | 提示选择参考；不硬过滤专业方向 |
| T11 | 学校限制与专业保留冲突 | 无候选，列明冲突，不自动放宽 |
| T12 | 同一输入和相同版本重复运行 | 结果及理由相同；排名稳定 |
| T13 | 第三候选仍有并列 | 可免费展开并列项，未暗藏结果 |

## 页面与数据验收

从未填写、全不了解、正常填写、全部并列、条件冲突、无专业资料各走完整路径。检查修改不丢草稿、二次提交不重复记录、对比数量约束、清空确实删除、旧报告读取快照、搜索旧响应不覆盖新响应、分享接收者不能读他人的结果。

数据验收包括来源追溯、年份范围、院校专业去重、专业类保留、AND/OR 真值、未知项分流、版本回退和正式数据不混入模拟条目。可用范围 partial 时必须在 UI 和接口中标明，不能用于整个方向的否定结论。

## 发布阻断条件

任何以下情况应暂停正式发布：核心报告需要看广告；虚构专业来源或覆盖率；年份不一致却输出当年可报结论；未知资料被当作不能报；公开接口允许写正式库；分享能读取他人输入；删除本机记录失效；正式包包含密钥；首发省份和真实规则不符。

微信具体类目、主体资格、备案、隐私接口、广告资质等需按上线时后台核查，不在本套文档中写成已获通过。广告未开通不阻挡无广告核心版发布；真实专业库未准备好时，不得假装已上线该能力，应先限定为有明确说明的体验测试。

## 测试与发布操作

先运行类型和引擎检查，再跑数据验证与关键页面测试，最后用 iOS、Android 真机验证。网络测试包含正常、弱网、断网和请求失败。性能按 04 的目标实测并记录设备、网络和样本数，不用开发机结果代表全部设备。

发布前备份已发布清单和数据版本；体验环境指向待发布版本进行检查。生产发布切换 current 指针，再发布对应小程序包。数据库变更必须向后兼容至少上一客户端版本，避免微信审核期间旧包不可用。回退优先关闭有问题的专业数据或广告开关，保持本机测算与已有报告可读。

## 运营指标

| 指标 | 定义 |
| --- | --- |
| 开始率 | 点击开始测算的会话数除以首页到达会话数 |
| 完成率 | 成功打开报告的会话数除以开始填写会话数 |
| 首次结果耗时 | 开始填写至首份报告首屏显示的时间，不含中途离开 |
| 比较使用率 | 进入比较的会话数除以打开报告会话数 |
| 专业查询成功率 | 有效查询返回成功的次数除以有效查询次数 |
| 输入不足占比 | insufficient_input 报告数除以全部报告数 |
| 反馈修正耗时 | 有效数据纠错收到至新版本发布的时间 |

统计仅发事件名、耗时区间、应用版本、地区支持状态和错误类别；不发自评、兴趣、专业意向、学校、姓名或报告全文。会话标识优先本机临时随机值，随会话结束失效，不追踪跨设备；最终采集和同意流程根据实际平台行为核查。

广告阶段另看填充、展示、收益与核心完成率，不承诺固定 eCPM。先有试运行基线，再设置阈值；若广告显著降低可用性，可远程关闭。反馈问题优先级为数据错误、流程阻断、阅读困难、非核心美化。
