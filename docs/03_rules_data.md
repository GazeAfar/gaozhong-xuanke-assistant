# 高中选科助手 推荐规则与数据规范

版本：0.1　日期：2026年11月25日

## 规则的性质

首版采用确定性启发式规则，不调用生成式模型决定组合排序。优势和兴趣由用户自评，反映填写时的主观情况；权重为产品设计建议，未经教育测量或预测效果验证。不得将内部得分称为录取概率、科学测评或高考预估成绩。

江苏规则来源 S01 明确了 2027 年 3+1+2 模式以及专业同时满足指定科目的要求。省份模式、适用年份和专业数据必须分别管理；2027 年文件不能自动证明 2029 年政策或招生要求，其他省份也不能直接沿用江苏配置。

## 合法组合

物理或历史选一科，化学、生物学、思想政治、地理中选两科，得到 12 组。固定编码如下，展示名称与内部编码分开维护。

| 编码 | 组合 | 编码 | 组合 |
| --- | --- | --- | --- |
| P_CB | 物理 化学 生物学 | H_CB | 历史 化学 生物学 |
| P_CP | 物理 化学 思想政治 | H_CP | 历史 化学 思想政治 |
| P_CG | 物理 化学 地理 | H_CG | 历史 化学 地理 |
| P_BP | 物理 生物学 思想政治 | H_BP | 历史 生物学 思想政治 |
| P_BG | 物理 生物学 地理 | H_BG | 历史 生物学 地理 |
| P_PG | 物理 思想政治 地理 | H_PG | 历史 思想政治 地理 |

科目编码为 PHYSICS、HISTORY、CHEMISTRY、BIOLOGY、POLITICS、GEOGRAPHY。后续支持 3+3 必须新增模式和组合生成器，不能只修改省份名称。

## 推荐执行顺序

1. 验证省份规则与目标年份状态，读取不可变规则版本和算法版本。
2. 生成合法组合，应用用户学校开班限制，保留每个被排除组合的原因。
3. 处理专业保留条件，只在目标年份已核实、范围充分的数据上应用硬约束；参考年份或资料不足仅提示，不硬过滤。
4. 计算输入完整度，决定是否允许排序；允许时计算优势和兴趣指标。
5. 生成并列排名、前三个候选与解释；不足三组按实际数量返回。
6. 输出全部组合状态、版本、来源年份和待核实事项，保存输入快照。

任何硬约束没有候选时返回 NO_FEASIBLE_COMBINATION，展示具体冲突并允许修改，禁止替用户撤销条件。推荐列表为空与服务失败是两种状态。

## 评分建议

设某科优势 a 为 1 至 5，归一化 A=(a-1)/4；兴趣 i 同理 I=(i-1)/4。某组合三个科目的 A 取算术平均，得到 Acombo。六科优势至少四科已知时开启排序，但只有自身三科优势均已知的组合可参与排序；含未知科目的组合进入「补充信息后可比较」区，未知绝不赋零。

六科兴趣全部为有效 1 至 5 时，启用 Icombo。建议内部排序值为 100×(0.65×Acombo+0.35×Icombo)。兴趣未启用或任一科未知时，所有组合统一使用 100×Acombo；部分兴趣只用于描述，不按组合分别换权重，以免横向不公平。

示例仅用于验证计算：某组合优势为 4、5、3，兴趣为 4、3、5，两项均值归一化都是 0.75，因此内部值为 75。这不是专业匹配率。算法文档记录 65/35 为待验证参数，产品负责人可在评审时调整，发布后必须升级算法版本。

排序按内部值降序，值距离某并列组最高分不超过 2 分的放入同组；该阈值为设计参数。组内按固定组合编码排序，仅为了稳定显示，不代表教育优先级。默认展示前 3 个候选，如第三个所在并列组还有其他组合，提示「另有同等接近的组合」并可免费展开，不藏掉平局。

已知科目数量达标但学校允许的组合均包含未知科目时，也返回 insufficient_input，不将缺少可评分组合误判为硬约束冲突。省份结构规则未核实目标年时，仅能在显著标明参考年份且用户选择参考后演示该结构的比较，不能声称目标年规则已确定。

所有优势相同且没有完整兴趣信息时，12 组并列，不生成虚假的第一名；界面显示「目前差异不明显」，优先提供全部组合比较。已知优势不足四科时不算排名，提示补充科目。完整度只表示填写充分程度，不输出“置信度 90%”。

## 推荐理由

理由必须由规则模板加输入事实生成。每组挑选最相关的两项已知事实，例如「你将化学的学习优势评为很有优势」「生物学是你比较喜欢的科目」。优势和兴趣冲突时同时呈现，例如「你喜欢物理，但目前自评稍有困难，可以进一步和老师确认学习负担」。

禁止通用断言「学地理更好赋分」「生物最简单」「物化生一定最好」。不得在缺少省级分布时根据一次校内考试推算赋分，也不输出高考总分。专业覆盖不作为默认评分权重，避免为了数量压过学生自身情况。

## 专业条目与匹配

匹配单位为具体来源中的「省份、资料年份、院校、层次、专业或专业类、选科要求」条目，不是全国抽象专业名称。一个专业在不同院校可能有不同要求。专业类保留原名称及包含专业原文，不擅自拆分成等价院校专业记录。

规则表达树支持 ALL、ANY 和 NONE。江苏 S01 的 2027 数据中，指定 2 或 3 科表示同时必选，应转为 ALL；不得误解析为任意选一。ANY 仅在实际来源明确表示或条件时启用，不能为方便匹配自行加入。首选科目限制独立保存，并与要求树做 AND。

| 条件示例 | 组合示例 | 结果 |
| --- | --- | --- |
| ALL 物理 化学 | 物理 化学 地理 | 满足该条已知选科条件 |
| ALL 物理 化学 | 物理 生物学 地理 | 不满足该条条件 |
| ALL 化学 生物学 且首选不限 | 历史 化学 生物学 | 仅选科条件满足，仍需核实当年计划 |
| NONE 且首选历史 | 物理 生物学 地理 | 不满足首选要求 |
| 原文无法确认 | 任意合法组合 | 待核实 |

目标专业为偏好时仅加提示，不影响排序值；选择保留方向时，只有该目标在已核实的当年数据范围中有完整且可判定的条目，才能形成硬约束。多个目标必须各至少存在一条满足已知条件的条目；缺少条目是未知，不是失败。对于无法证明完整性的目标，保留软提示并告知「该方向资料尚不充分」。

匹配状态是三态：eligible、ineligible、unknown。当前年数据与历史参考数据分开；对历史参考库的 eligible，展示必须带「参考 YYYY 年」，不得写成目标年「可以报考」。

## 覆盖率与数量

首版不展示“全国 96% 专业可报”等指标。若以后展示数量，仅统计当前明确数据范围内的已审核条目，展示分子、分母、年份、层次、去重口径和未知条目数；它只能叫「已收录条目的选科条件匹配比例」。同一专业的多所院校条目不能冒充不同专业数量，选科要求表也不能冒充当年招生计划。

## 数据实体

| 实体 | 必须字段 |
| --- | --- |
| ProvinceRule | provinceCode、mode、applicableYears、version、status、sourceId |
| Source | id、title、publisher、url、publishedAt、checkedAt、sha256、usageNote |
| Dataset | id、provinceCode、dataYear、applicableYears、kind、level、version、status、sourceIds、completeness |
| Offering | id、datasetId、institutionCode、institutionName、majorCode 可空、majorName、level、firstSubject、requirementTree、requirementRaw、reviewStatus |
| MajorCatalog | id、name、category、aliases、sourceId；只用于查找和映射，不替代 Offering |
| ChangeLog | version、previousVersion、added、changed、removed、reviewer、publishedAt |

kind 区分 subject_requirements 和 annual_plan。applicableYears 只有来源明确授权范围时才能填入；未确认的未来年份不能默认包含。completeness 为 full 或 partial，必须说明范围；局部审核数据可供带范围查询，但不得据此排除整个专业方向。

## 数据维护和发布

发现官方文件 → 确认使用范围及来源 → 保存原始文件与哈希 → 标准化 → 自动校验 → 人工复核 → 预览差异 → 发布新版本 → 更新公共清单。来源公开不等于自动获得任意商业再分发授权，正式导入前核实使用方式；本轮未完成全量数据采集或授权判断。

校验要求：所有条目可追溯来源；科目代码合法；AND/OR 不含歧义；同一业务键重复必须检查；缺失代码不自动丢弃；解析不了的设 unknown 并进入复核队列。新旧数量变化超过 10% 时标记人工检查，该比例是维护阈值。发布者显式检查所有异常后才能发布。

将 full 版本作为专业硬约束数据前，对所有不同要求表达式至少各核一条，同时核验 12 个组合的匹配真值；人工抽检至少 30 条且覆盖不同院校、专业类、无要求和多科要求。零重大错误才放行；发现一条 AND/OR 错误则停止发布并扩大复核。

版本不可覆盖修改，使用 current 指针切换发布和回退。每份报告保存 algorithmVersion、provinceRuleVersion、datasetVersion 可空、目标年与资料年。旧报告不默默重算；数据修正后提示可重新生成。
