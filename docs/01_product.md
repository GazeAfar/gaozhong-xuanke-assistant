# 高中选科助手 产品框架

版本：0.1　日期：2026年11月25日

## 产品目的

让家长和学生在一次简短操作后，看懂哪些组合值得优先讨论、推荐依据是什么、与专业方向有哪些关系，并能修改输入再次比较。产品帮助缩小讨论范围，最终仍需结合学生意愿、学校开班和当年招生要求。

用户已经明确：轻量、免费、低操作成本、快速出结果；基础测算和核心报告免费，以微信小程序流量主广告探索变现；激励广告和轻游戏仅能作为可选补充，不能阻挡核心流程；先完善产品、功能、技术、页面、样式文档，再开发。

## 用户与主要场景

| 用户 | 当下问题 | 首次使用应拿到的结果 |
| --- | --- | --- |
| 高一家长 | 科目多，不知道从哪里比较 | 三组候选、推荐理由、需要核实的条件 |
| 高中生 | 家长意见与自己的感受不一致 | 可调整的科目优势与兴趣，不被单一分数定论 |
| 已有组合的家庭 | 想了解专业方向受哪些限制 | 指定组合的选科条件匹配情况与来源 |

首版按普通类选科场景设计。艺术体育、专项招生、综合评价等不混入普通类匹配结论。家长可直接代填，不要求录入孩子姓名、学校、身份证、电话或照片。

## 产品结构

底部导航建议为「测一测」「查专业」「我的记录」。组合比较和结果报告从测算结果进入，不新增常驻导航。无需注册即可浏览、填写、测算和使用本机记录；没有自建账号系统，也不承诺跨设备同步。

主路径：打开测算首页 → 确认省份和预计高考年份 → 填六科优势 → 可选兴趣与专业意向 → 查看结果 → 比较或修改。本机可保存草稿，返回继续填写。首次基础路径目标为 2 分钟以内；这是体验目标，需用真实用户测试验证。

## 首版范围

| 范围 | 首版要求 |
| --- | --- |
| 省份 | 建议江苏首发；未支持省份显示暂未开放，不套用江苏规则 |
| 组合 | 配置化生成江苏 3+1+2 的 12 种组合 |
| 测算 | 六科优势快速自评，兴趣可选；输出可解释的候选组合 |
| 结果 | 前三组、优势与兴趣依据、专业条件状态、修改入口 |
| 比较 | 同屏比较 2 至 3 组；全部组合可查看 |
| 专业 | 按专业或院校搜索选科要求，明确省份、年份、来源 |
| 记录 | 本机草稿、报告记录、删除、重新测算 |
| 维护 | 数据文件导入校验、预览、发布、版本回退，无需先建大型后台 |
| 变现 | 核心无广告门槛；后续接结果末尾广告，激励广告另作可选实验 |

首版不安排完整职业规划问卷、人格测试、大学录取预测、AI 对话、付费会员、积分商城、社区、排行榜和小游戏。上述为控制开发范围的建议，避免维护成本超过轻量工具本身的价值。

## 免费与广告

免费内容包括全部组合建议、推荐理由、专业查询、核心报告、修改重测、组合对比、本机记录和基础分享。不得将「完整报告」或前三名之外的组合做成必须看广告才能查看的内容。

首版广告能力默认关闭，即使流量主尚未开通，产品也应完整可用。获得广告接入条件后，先评估结果末尾单一广告位；输入表单、首屏结论、返回操作、提交按钮附近均不放广告。不自动弹出视频，不用插屏打断结果。

可选激励实验仅考虑额外视觉主题等非核心权益，不预设收益，也不承诺平台一定允许该场景。额外测算次数暂不设限；若未来确有高成本扩展服务，再单独设计额度，不能减少现有核心能力。广告接入条件、类目和规范以提审时微信后台及官方文档复核结果为准。

## 产品效果

首要观察测算完成率、结果到达时间、改选与比较使用率，以及家长能否复述推荐理由。广告收入为后续指标，不能替代核心流程的可用性。初期不编造日活或收益目标；先做 5 至 8 个家庭的可用性测试，记录卡点后再定基线。

## 对用户的表达

主标题建议「选科之前，先比较一下」。按钮使用「开始测算」「查看建议」「比较这几组」。结果说明「根据你填写的科目优势与兴趣整理，适合用来和孩子一起讨论」。不用「最优人生选择」「精准预测高考」「保证可报」「超过全国多少人」等未经验证的说法。
