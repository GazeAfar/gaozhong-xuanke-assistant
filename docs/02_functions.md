# 高中选科助手 功能说明

版本：0.1　日期：2026年11月25日

| 编号 | 功能 | 级别 | 完成条件 |
| --- | --- | --- | --- |

## F01 地区和年份

省份必须由用户确认，首发可预选江苏但在页内明显展示，不申请定位权限。预计高考年份提供未来若干年和「还不确定」，不得根据当前时间悄悄锁死。可根据高中入学年份辅助填入，但允许修正，不索取出生日期。

目标年份与数据年份分别保存。目标年没有已核实数据时，先展示「专业条件参考 YYYY 年资料」，由用户显式选择是否查看该参考库；不选择则继续做科目比较，隐藏专业匹配结论。年份不确定时不输出当年可报结论。

## F02 六科优势

六科：物理、历史、化学、生物学、思想政治、地理。优势采用 1 至 5 档按钮：比较吃力、稍有困难、一般、比较擅长、很有优势，另有「还不了解」。每科单选，默认未填写；「一般」不得作为自动默认值。

必填的是对每科明确作答，包括「还不了解」。未答项目定位至第一处并提示「还有科目没选，补充后就能比较」。选择不了解不当作差科，按 03 的完整度规则处理。兴趣作为独立可展开区域，不与优势混为一项。

首版不要求输入九科成绩。校内原始分数不能直接代表跨科难度、全省位次或高考赋分，避免增加录入负担和制造精确感。以后支持成绩时必须同时解释比较口径。

## F03 兴趣与专业意向

兴趣默认跳过，不给用户预设态度。启用后六科各选 1 至 5 档或不了解，文案从「很不喜欢」至「很喜欢」。部分填写仅展示已知描述，不参与数值排序；用户可一键撤销此模块。

专业意向最多选 3 个具体专业，选择「还没有方向」与选择专业互斥。默认是偏好；用户可另选「希望保留这些方向」。专业库不充分时保留文本关注项，但不提供约束能力，不把未知专业视为不能报。

学校开班限制放在「更多条件」中，可勾选学校实际提供的组合；默认全部允许。学校限制仅来自用户输入，不推断学校开班情况。限制后没有组合时，给出冲突列表和清除条件入口，禁止偷偷放宽条件。

## F04 报告

报告顺序：输入概况 → 候选前三组 → 每组理由 → 专业条件与来源年份 → 组合比较 → 调整入口 → 方法说明。每个结果至少有两条来自输入的解释；资料不足时给出「仍需补充」而不编造理由。

评分仅供内部排序；默认界面用「优先看看」「也值得比较」「信息待补充」，不展示 92.7% 匹配率。并列的候选标记接近，不强行判断胜负。点击「查看全部组合」可免费查看 12 组及筛选状态。

优势已知不足 4 科时，不产生前三名排序，转为组合浏览，并列出需要补充的科目；报告仍可打开。优先组合不足三组时只展示实际数量，不补入不合条件的组合。

## F05 比较

从推荐卡片或全部组合选择 2 至 3 组。维度为所选科目、已知优势、已知兴趣、专业条件匹配和资料完整度。无数据用「未提供」或「待核实」，不以零代替。小屏采用纵向维度分组，不让正文缩小到难读的字号。

## F06 查专业

输入专业名或院校名，分页返回院校与专业条目。单条展示专业名称、院校、选科要求原文、标准化解释、数据年、来源和是否为当年招生计划。专业类别介绍和院校具体要求分开显示，不把某所院校的要求推广到全部院校。

筛选支持当前组合和资料年份。匹配状态只有「满足已知选科条件」「不满足该条条件」「待核实」。满足选科条件不代表分数、体检、招生计划等其他条件满足。暂无数据时显示可用的官方查询入口和说明，禁止用模型补全。

## F07 F08 记录与分享

草稿默认保存本机一个；报告最多保存最近 20 份，超出时先提示将移除最早记录。重新测算生成新记录，不覆盖旧报告。记录存输入快照与版本；算法或数据已更新时可查看旧报告，也可主动重算。

提供单条删除和清空全部，本机删除即移除产品存储内容。换手机或清理微信缓存可能丢失，本机记录页说明这一点。分享默认不携带自评、兴趣、专业意向和报告标识；接收者进入工具首页，不可读取原用户的报告。个性化报告海报属于后续功能，需单独预览确认。

## F09 F10 异常与广告

| 情况 | 行为 |
| --- | --- |
| 首次断网无公共规则缓存 | 保留草稿，提示联网加载规则，提供重试 |
| 已缓存有效规则后断网 | 可计算科目建议，显示版本；在线专业查询不可用 |
| 专业服务超时 | 保留报告，专业区域局部重试，不整页报错 |
| 缓存文件损坏 | 不使用损坏规则；重新加载，保留用户草稿 |
| 本机空间不足 | 当次结果仍可看；提示记录未保存，提供删除入口 |
| 多次点击提交 | 按钮短暂禁用，只生成一份报告；不得重复跳转 |
| 广告未开通或无填充 | 不显示空广告容器，不影响报告 |
| 激励中途关闭 | 留在原页，未获得附加权益；不清空任何核心内容 |
| 广告完整观看回调重复 | 一次观看仅发一份附加权益，结果幂等 |

首版只预留广告开关，不实现虚假的视频按钮。F10 进入开发范围前补充权益名称、有效期和审核结果。
