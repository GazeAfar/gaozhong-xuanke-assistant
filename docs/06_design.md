# 高中选科助手 样式与组件规范

版本：0.1　日期：2026年11月25日

## 视觉方向建议

采用清晰、安静、容易阅读的工具界面，以蓝色作为主要操作色，白色和浅灰承载内容。受众主要是家长，优先保证正文、档位按钮和结果理由清楚；不采用儿童插画、复杂罗盘背景、满屏渐变或装饰性图表。该视觉方向为首轮建议，并非用户已确认稿。

## 设计变量

| 变量 | 建议值 | 用途 |
| --- | --- | --- |
| primary | #2457D6 | 主按钮、当前导航、选中描边 |
| primarySoft | #EDF2FF | 选中浅底和说明底色 |
| background | #F6F7FB | 页面背景 |
| surface | #FFFFFF | 内容卡片 |
| textPrimary | #172033 | 标题、正文 |
| textSecondary | #4B5563 | 次级文字 |
| border | #D7DEEA | 描边和分隔 |
| successText | #166534 | 已知条件满足文本 |
| warningText | #92400E | 资料待核实文本 |
| errorText | #B42318 | 输入错误文本 |
| radiusCard | 24rpx | 卡片圆角 |
| radiusControl | 16rpx | 按钮与档位圆角 |
| spaceUnit | 8rpx | 间距基数 |

颜色只承担辅助作用，匹配状态必须同时有文字。禁用按钮用浅底与深灰文字，不能让未选按钮看起来都不可点击。不得靠一层低透明度处理所有未选内容。

## 字体与尺度

| 用途 | 建议字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 首页主标题 | 48rpx | 600 | 1.35 |
| 页面标题 | 40rpx | 600 | 1.4 |
| 组合名称 | 38rpx | 600 | 1.4 |
| 卡片小标题 | 34rpx | 600 | 1.45 |
| 正文及主要控件 | 32rpx | 400 至 500 | 1.6 |
| 次级说明 | 28rpx | 400 | 1.55 |
| 来源辅助文字 | 26rpx | 400 | 1.55 |

优先使用系统字体，不加载大字体包。rpx 基于 750 设计稿，在窄屏仍需保证正文实际字号不低于 16 CSS 像素，辅助文字不低于 13；使用最小像素值或响应式覆盖，不能单纯等比缩小。正文响应系统大字体，按钮和卡片允许增高。

## 布局与间距

页面左右留白 32rpx，卡片内边距 32rpx，卡片间 24rpx，模块间 40rpx，标题和正文间 16rpx。长说明分段，不靠连续分割线形成密集表格。结果首屏主要区域控制在一个组合加核心解释，不塞进三张拥挤卡片。

主按钮高度至少 96rpx 且实际触控不小于 44×44 CSS 像素；固定底栏加系统 safe-area 底部内边距。正文底部补齐底栏高度，键盘弹起时不遮输入和错误提示。完整报告采用自然滚动，不做横向滑屏才能找到核心结论的设计。

## 组件要求

| 组件 | 结构 | 关键状态 |
| --- | --- | --- |
| PrimaryButton | 文本、可选加载标记 | normal、pressed、loading、disabled |
| RatingSelector | 科目标题、1 至 5 档、不了解 | unanswered、selected、unknown、error |
| CombinationCard | 组合、排序组、依据、待核实项、操作 | ranked、tied、needsInput、excluded |
| YearNotice | 目标年、资料年、说明及选择 | verified、reference、unavailable |
| RequirementBadge | 图标加文字 | 满足该条条件、不满足、待核实 |
| SourceBlock | 标题、发布者、日期、复制链接 | 有链接、暂无资料 |
| EmptyState | 简短标题、原因、一项主要操作 | 无输入、无记录、无结果 |
| ErrorState | 受影响模块、可重试操作 | 断网、超时、版本变化 |

RatingSelector 的 6 个选项不挤在窄屏同一行，可分为两至三行；每项保留完整语义，不能只显示不明所以的 1 至 5 数字。选中态用蓝色描边和文字勾选，取消后恢复未答。

CombinationCard 不用百分比进度条或雷达图暗示预测能力。未知资料区使用温和提示底色，不用红色警告让家庭误以为学生能力有问题。推荐理由突出用户输入事实，不做模板化的空洞赞美。

## 动效与图标

图标统一线性风格，主要功能均有文字标签。过渡 150 至 200ms，尊重减少动态效果偏好；不做连续旋转罗盘、开奖动效、倒计时和虚假等待。小型加载只出现在真正网络请求的模块。

## 文案示例

| 场景 | 建议文案 |
| --- | --- |
| 首页说明 | 填一填科目优势，看看哪些组合值得比较 |
| 输入不足 | 有几科还不了解，先补充后再比较会更有帮助 |
| 并列 | 这几组目前差异不明显，可以再看看兴趣和专业方向 |
| 年份不一致 | 目标为 2029 年高考，当前专业条件参考 2027 年资料 |
| 匹配成功 | 满足这条资料中的选科条件 |
| 专业数据缺失 | 这个方向的资料还在整理，暂时无法确认 |
| 本机记录 | 记录保存在这台设备，换设备后可能无法找回 |

示例年份只用于文案结构，运行时从目标年与资料年动态读取。不可写死 2029 或 2027。

## 视觉验收

一般正文对比度以 4.5:1 为目标，最终对实际前景背景组合测量，不能只凭色值名称判断。大字体和放大后无裁切；按钮可触达；读屏可按表单顺序读取；不只用颜色区分状态；横竖屏与窄屏不出现必要操作横向溢出。正式视觉评审至少提供首页、填写页、报告页三张真实布局稿。
