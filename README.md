# 高中选科助手（Gaozhong Xuanke Assistant）

> 面向全国高一学生与家长的免费新高考选科决策与就业分析工具（支持 `3+1+2` 并持续扩展 `3+3` 省份）。
> 在线访问：https://xuanke.visc.cn

## 核心特性

- **全国省份门户 + 分省独立工作台**：首页（`/`）按省份进入对应高考模式，首批完整上线**江苏省（`/jiangsu`）**，收录江苏省教育考试院公布的 **79,753 条**在苏招生高校专业选科要求。
- **多轮成绩与排名画像**：支持录入多次月考、期中、期末的主科（语数英）与 6 门选考科目成绩及班级/年级排名，自动计算加权均分、班排/年排百分位与上升/稳定/下滑趋势。
- **独立 Tab 视图 + 沉浸式选科白皮书**：分为「成绩录入」「选科白皮书」「组合对比」「院校专业库」4 个清爽独立视图，支持一键导出 A4 PDF。
- **内置就业趋势研判（零外部 API 依赖）**：内置面向 2027–2030 届高考学生（对应 2031–2034 年本科毕业）的行业趋势、央国企/考公考编去向与本硕学历门槛分析；亦支持通过服务端环境变量可选接入 OpenAI 兼容大模型。
- **SEO & GEO（AI 搜索）友好**：内置服务端直出（SSR）独立专题页（`/modes`、`/fufenzhi`、12 个江苏选科组合详情页、`/privacy`、`/disclaimer`、`/contact`），自动生成绝对路径 `/sitemap.xml`、`/robots.txt` 与 `/llms.txt`。
- **隐私优先与安全设计**：
  - 所有学生称呼、成绩、排名与暂存快照**仅保存在用户本机浏览器（`localStorage`）**，服务端不存储、不共享任何个人成绩记录。
  - 服务端内置基础 IP 限流、请求体大小限制（`128 KB`）、静态目录路径穿越防护、HTTP 安全响应头，且拒绝前端传入任意外部 AI 地址以杜绝 SSRF 风险。

## 目录结构

```text
├── web/                  # 前端页面、样式、交互脚本与静态资源（语雀风格极简 UI）
│   ├── index.html        # 全国省份选择门户首页 (/)
│   ├── jiangsu.html      # 江苏省 3+1+2 选科完整工作台 (/jiangsu)
│   ├── app.js            # 前端视图切换、本地暂存、白皮书渲染与院校检索
│   ├── styles.css        # 全站响应式样式与 A4 打印样式
│   └── llms.txt          # 面向 ChatGPT / 豆包等 AI 搜索引擎的站点说明
├── server/               # 零外部框架依赖的 Node.js HTTP 服务与分析引擎
│   ├── index.mjs         # HTTP 路由、限流、安全响应头、静态与 SSR 分发
│   ├── seo-pages.mjs     # 独立 SSR 专题页与动态 sitemap.xml 生成器
│   ├── advisor.mjs       # 多次考试加权评分、排名百分位与 12 组合推荐算法
│   ├── ai-career.mjs     # 毕业年就业形势分析引擎（内置规则 + 可选 LLM）
│   └── store.mjs         # 79,753 条官方专业数据内存索引与检索
├── packages/             # 共享类型契约与纯函数规则引擎（TypeScript）
├── data/                 # 官方选科数据目录（data/runtime/ 已忽略，不入库）
├── deploy/               # 生产部署文件（Dockerfile、Nginx、systemd、阿里云指南）
└── tests/                # 自动化测试套件（29 项用例）
```

## 快速开始

环境要求：Node.js `>= 20`

```bash
# 安装依赖
npm install

# 运行全部 29 项单元测试（包含真实 79,753 条官方数据校验）
npm test

# 启动本地 Web 服务（默认监听 0.0.0.0:3000）
npm run start:server
```

启动后访问：
- 全国首页：http://127.0.0.1:3000/
- 江苏工作台：http://127.0.0.1:3000/jiangsu
- 全国新高考模式详解：http://127.0.0.1:3000/modes
- 等级赋分制详解：http://127.0.0.1:3000/fufenzhi
- 站点地图：http://127.0.0.1:3000/sitemap.xml

## 生产部署

详见 [deploy/DEPLOY_ALIYUN.md](deploy/DEPLOY_ALIYUN.md) 或直接使用 [deploy/Dockerfile](deploy/Dockerfile)。常用环境变量：

| 变量名 | 说明 | 默认值 |
| --- | --- | --- |
| `PORT` | 服务监听端口 | `3000` |
| `HOST` | 监听地址 | `0.0.0.0` |
| `SITE_URL` | 站点规范域名（用于 `sitemap.xml` 与 `robots.txt`） | `https://xuanke.visc.cn` |
| `AI_BASE_URL` / `AI_MODEL` / `AI_API_KEY` | 可选：服务端接入 OpenAI 兼容大模型（留空则使用内置分析引擎） | 空 |
